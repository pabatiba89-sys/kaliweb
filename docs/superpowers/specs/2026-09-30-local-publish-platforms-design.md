# 本机发布十平台登录映射设计

## 目标

发布设置完整展示 Kali Publish 当前支持的十个平台，所有平台都能通过本机浏览器登录流程新增或重新登录。

## 平台契约

1. 小红书
2. 视频号
3. 抖音
4. 快手
5. TikTok
6. YouTube
7. X
8. Instagram
9. Facebook
10. 支付宝生活号

十个平台均属于浏览器登录平台。前端继续使用 `/login?type=<平台编号>&id=<账号名称>` 打开本机登录流程，不新增 API 凭据导入交互。

## 界面行为

- “新增本机账号”的平台下拉框按编号顺序展示全部十个平台。
- 本机账号列表能把 `type=10` 正确显示为“支付宝生活号”。
- 1–10 的已有账号都显示可用的“重新登录”操作。
- 支付宝生活号使用独立平台标签配色，不改变卡片布局。

## 实现边界

- 仅修改独立站前端的平台映射、登录类型、标签样式和自动化测试。
- Kali Publish 已定义 `type=10` 并支持十个平台的浏览器登录，本次不修改该仓库。
- 定时发布支持范围不属于本次修改。

## 验收

- 自动化测试确认十平台映射完整。
- 自动化测试确认 7–10 均能构造本地登录 URL。
- 完整测试、Astro 检查和生产构建通过。
