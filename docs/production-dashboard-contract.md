# 创作数据大屏统计口径

当前大屏复用已登录账号/团队可见的作品列表，只统计成功且存在归档媒体地址的成品。视频包含数字人、混剪、各类包装、Seedance 和音乐视频；`production/list` 不传 scene 已覆盖混剪和包装，不能再叠加 `video-mix/list`。音乐按返回的成品 `items` 计数，一个任务的多个成品分别计数。

所有列表完整分页并按来源内记录 ID 去重；接口失败、响应异常、分页重复或提前结束均不将不完整数据当成精确总量，也不据此宣告每日目标未完成。

每日目标固定为 3 个成功视频。现有接口缺少不可变的完成时间及带时区的时间戳：大屏明确提示“今日按作品创建日期统计”。没有时区的服务端时间保持其日期，不用 `updated_at` 猜测完成时间，以免改标题、发布或其他编辑让旧作品重复进入今日。浏览器每分钟更新日期并在页面可见时刷新。

## 后台后续需求（仅列契约，本次不改后台）

若要精确统计“今天完成”的作品，后台需保存不可变的 `completed_at`（首次成功时写入），返回含时区的 ISO 8601 时间，并明确账号/团队统一业务时区。建议另提供鉴权汇总接口，直接返回各类型成功成品的累计与当天数量、目标日期、时区和 `daily_video_target=3`，避免大型团队需要在浏览器完整扫描历史。汇总需沿用现有团队权限、按成品去重且排除失败/草稿/处理中。
