# 创作数据大屏与报表

自 v1.6.43 起仅调用鉴权的 `GET /api/statistics/options` 和 `GET /api/statistics/dashboard`。不再逐页扫描作品列表、不刷新上游任务、不调用生成接口，也不在统计接口失败时回退到不完整列表或数字零。

选项及默认值使用 options 的 `value`，不按中文 label 组装参数。团队/个人、成员、日期范围、按天/按成员分组、七类资源共用这套值；成员名称保留原文，不展示团队标识或账号隐私字段。素材、数字人、声音和配音成品使用小卡片，视频、音乐、图片使用主要卡片。报表明细可展开查看。

- 检查 JSON 业务 code；即使 HTTP 200，401/403/400 也分别显示登录、权限、参数错误。缺失卡片、非法计数及接口异常不解释为零。
- 卡片累计读取 `total_count`，所选日期/期间读取 `period_count`；文案区分今日完成、当日完成与期间完成。累计截至响应的 `end_date`，不包括之后的资产。
- 默认单次大屏请求复用今日视频数量。查询历史、筛掉视频或改变期间时，另以同一团队/成员范围请求 `period=today&resource_types=video&group_by=day`，每日 3 个视频的提醒始终使用这份今日数据。
- 今天、跨日刷新与日期上限统一按 `Asia/Shanghai` 计算。自定义起止日期需成对、不在未来、范围含起止日且最多 366 天。响应 `generated_at`、日期与计数口径由后台负责，前端不使用可变的 `updated_at` 推测完成时间。
- `series` 按后台的 day/member 维度展示。按成员无产出时允许空数组；历史离队成员名称缺失时回退“用户 ID”。筛掉全部资源的操作被阻止。
- 请求切换时忽略旧请求结果；不同账号、日期及筛选不共用显示结果。数字动画只使用接口真实数量。

后端采用当前仍存在、成功、可见的资产实时汇总；删除、分配与团队变动可能改变历史结果。音乐成品按父任务创建日归日，视频去重及其他源表口径全部由统计接口负责，前端不再自行拼算。没有不可变完成事件/快照，因此跨日完成仍归创建日。

本次仅修改前端，后台源码保持只读。
