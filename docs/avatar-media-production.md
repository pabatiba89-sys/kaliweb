# 数字人拍摄示范素材

用途：数字人制作文档中的教学示范。用户于 2026-10-30 授权自行制作替代素材。

两张图片通过内置 imagegen 工具制作，人物为虚构人物；第二张以上一张为形象参考。图片未作为真实训练素材或实际数字人口播成片展示。30 秒无声字幕视频由原创图片和文字图形组成。

资源位于 `public/docs/avatars/`；视频构建脚本为 `scripts/build-avatar-guide-media.py`。运行环境使用现有 FFmpeg、Pillow 和系统 Arial Unicode 字体，无新增在线服务。

最终提示词规格：

1. `filming-setup.png`：原创写实横向 3:2 拍摄场景。虚构的三十岁左右中国女性，整齐深色齐肩发、素色灰绿色衬衫，坐在浅奶油色简洁室内。以侧前方观察视角展示人物、固定在三脚架上的手机和照向面部的柔光箱；手机接近眼睛高度，人物自然说话、面部无遮挡，手低于胸前，画面没有其他人、文字、水印、界面或品牌标识。配色为薄荷、灰绿、奶油色。明确这是教学拍摄场景，不是产品生成效果。
2. `portrait-example.png`：以第一张为人物与服装参考，将视角改为手机镜头正面视角。人物直视镜头，正脸、自然闭嘴、神态放松；头顶与双肩留空间，显示到腰部附近，手自然放置，背景简洁且光线柔和均匀。移除手机、三脚架和柔光箱，不出现五官网格、界面、文字、水印或夸张滤镜。保留同一虚构人物的自然五官。

视频内容：机位与光线 → 面部可见 → 视频 30–120 秒 → 选自然正面照 → 形象与本人授权。每段 6 秒，共 30 秒。提供简体中文、繁体中文、英文视频、封面及 WebVTT 字幕。网页不自动播放，默认不预载视频，支持播放、全屏和下载。

拍摄事实依据：[闪剪官方注意事项](https://openapi-doc.shanjian.tv/8489759m0)。文字以喀理现有表单为准，不照搬第三方品牌名或训练时长承诺；选图与机位的补充建议明确标为建议。
