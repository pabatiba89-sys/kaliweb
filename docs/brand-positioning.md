# 喀理官网营销定位 · 2026-10-26

## 核心主张

让你和你的品牌，被更多人记住。以 AI 内容生产和持续分发服务个人品牌与企业品牌的长期建设。

产品链路：热点选题 → AI 文案 → 数字人或 AI 视频 → 智能剪辑与包装 → 一键多平台发布。声音、音乐、图片为配套创作资产；MCP 与 API 连接团队已有工具和自动化流程。

中文可使用“个人 IP”，其他语言按当地习惯表达 personal brand，而非知识产权 IP。英文主张为 Build a brand people remember。SEO 标题以真实产品类别和搜索意图命名，首页标题同时说明 AI 内容、视频与个人品牌，不只放口号。

## 事实与边界

用户已确认先按代码可核实的 10 类发布平台编写，不使用“全网数十个平台”。清单为小红书、视频号、抖音、快手、TikTok、YouTube、X、Instagram、Facebook、支付宝生活号。发布前需要账号连接与本机发布服务配置，不宣称无配置或平台无条件可用。

MCP `/health` 已核实返回正常；公开连接地址是 `https://mcp.kaliai.fun/mcp`，账号访问凭据只在登录后查看。API 服务按用户提供的产品定位介绍；未拿到对外文档前引导联系团队，不编造 SDK、API 套餐或接口承诺。

不承诺涨粉、播放量、转化率或完成时间，不编造客户证言。素材、授权和费用说明保留为决策信息，不占据首页主叙事。

2026-10-27 用户要求公开页面不出现“流程示意”“创作示意图”“工作台预览”等展示提示；同时清理帮助页里的迭代批次、预留截图位置等内部制作说明。页面保留产品能力、具体操作与必要的费用授权信息，不把装饰素材描述成真实成片。

## 参考站的表达方式

用户指定参考 https://onmeai.cn/。已查看桌面首屏与滚动后的影片章节：采用短主张、连续的能力章节、大幅视觉场景和独立开发者入口。喀理借鉴其叙事与画面比例，保留工作台的深墨绿与薄荷绿；制作五个业务场景，不复制对方的模型聚合定位、品牌素材或粒子动画。公开正文直接输出 HTML，章节保留独立 URL 和普通滚动阅读，照顾搜索抓取、移动端及减少动画偏好。

2026-10-27 用户纠正：参考重点还包括鼠标悬浮响应与有节奏的自动变化，只有静态分章不算完成。采用原生 Canvas 与 CSS 实现原创粒子形态切换、指针视差和章节循环动画，不增加动画框架或外部依赖。首屏五阶段自动轮播，可手动选择和暂停；移入、键盘焦点、离屏、后台标签页均暂停轮播，减少动态效果偏好下只保留手动切换。各能力场景展示与业务相关的循环变化，正常滚动和静态正文继续保留。

## 页面实施

公开官网全部 24 种语言的营销主张、页面级标题与描述、产品正文与 CTA。首页、已有产品、价格、关于、联系和帮助目录统一新定位；操作教程保留可核实步骤，法律正文不作营销改写。新增文案创作、智能剪辑、多平台发布和开发者接入四个页面，所有语言均提供完整内容。

采用独立、全语言的品牌文案字典和页面构建器覆盖前两批局部修订。核心文案本地维护，不在运行时调用翻译服务。保留当前索引白名单，不因文案翻译自动开放尚未做母语关键词审校的语言。

## 验收

检查所有语言文案键完整、页面链接有效、标题与描述唯一、可见内容与结构化数据一致、无英文兜底；检查中文、德法、日韩及 RTL 桌面/手机布局和五步 Demo。验证 24 语言全部构建、SEO、工作台全语言索引和发布连接条件。检查通过后提交推送并核实线上。
