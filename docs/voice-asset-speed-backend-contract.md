# 声音资产语速范围后端适配

## 前端需求

- 入口：工作台「数字人资产」→「我的资产」→「我的声音」→「编辑」。
- 语速范围：`0.2` 到 `2.0`。
- 步进：`0.1`。
- 页面展示：始终保留一位小数，例如 `1.0x`、`2.0x`。
- 更新请求：`POST /api/ai-voice/update`，同时提交 `speed`、`voice_speed`、`voiceSpeed`；现有接口以 `speed` 为准。

## 当前阻塞

只读后台的 `routes/ai_voice.py::parse_voice_speed` 当前仍校验 `0.5-2`，因此 `0.2`、`0.3`、`0.4` 会被拒绝。

## 后端所需改动

1. 将声音资产训练与更新共用的 `parse_voice_speed` 最小值从 `0.5` 改为 `0.2`，最大值保持 `2.0`。
2. 将错误提示同步为“声音速度范围为0.2-2”。
3. 保存前按一位小数规范化，确保列表接口回显一致。
4. 增加边界测试：`0.2`、`2.0` 接受，`0.1`、`2.1` 拒绝，`1` 回显为数值 `1.0`。

文字转语音页面的独立语速参数不在本次范围内，可继续保持现有 `0.5-2.0` 约束。
